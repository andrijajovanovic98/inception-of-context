Miert nem elegendo onmagaban a sima vektoros kereses a forraskodban?

Search Engine

  • Gyengesege: Nem ert semmit a szemantikabol, ha nincs kozos szo a kerdesben es a kodban.

Part 2

Szimbolum elofeloldas: Hallucinaciok kikuszobolese

Hogyan garantaljuk a 100%-os tenyszeru pontossagot a kodszimbolumoknal?

Anti-Hallucination
A problema: LLM szimbolum hallucinacio Kockazat
  • A subject kovetelmenye: "The /ask system must avoid hallucinating code symbols. Questions such as 'is there a function called X?' must be answered based on known indexed information."
  • Ha egy 3B-s modellnek csak annyit kerdezunk: "Letezik-e power() fuggveny?", konnyen azt mondhatja: "Igen, a calculator.py tartalmazza", holott nincs benne!
  • A tisztan statisztikai nyelvi modellek hajlamosak a "valoszinunek tuno" valaszokra a tenyek helyett.
Az IoC megoldas: Determinisztikus elofeloldas Megoldas
  • 1. Mintafelismeres: Kiszurjuk a szimbolumkerdeseket regex-szel (pl. van-e X fuggveny?, what functions exist?).
  • 2. AST szimbolumtar: Ellenorizzuk az indexelt szimbolumokat az AST metaadatokbol (fuggvenyek, osztalyok).
  • 3. Teny-injekcio: Ha a felhasznalo a power-rol kerdez, es az AST-ben nem szerepel, a rendszer explicit tenykent adja at az LLM-nek: "A keresett szimbolum NEM letezik a kodbazisban."
Vedesi tipp: Ezzel a ketlepcsos megoldassal garantaljuk, hogy a 3B modell soha ne talaljon ki nem letezo fuggvenyeket!
Part 2

Reciprocal Rank Fusion (RRF) algoritmus

Ket kulonbozo skalan mozg pontszam matematikai egyesitese

Algorithm
A fuzios formula Matematika

A vektoros koszinusz hasonlosag (0 es 1 kozott) es a BM25 pontszam (0-tol vegtelenig terjedhet) nem adhato ossze kozvetlenul normalizalas nelkul. Az RRF a helyezesek (rangok) alapjan szamol:

RRF_Score(d) = SUM [ 1 / ( k + rank_i(d) ) ] k = 60 (standard simito konstans)
  • Ha egy kodreszlet mindket rangsorban elol vegez, az RRF pontszama maximalis lesz.
  • Ha csak az egyikben van elol, a kiegyensulyozott kiertekeles megakadalyozza a tulindexelest.
Implementacio: p2/retriever.py Kod
def hybrid_retrieve(query: str, top_k: int = 4): dense_hits = chroma_client.query(query, n=top_k*2) sparse_scores = bm25.get_scores(query.split()) rrf_scores = {} for rank, doc_id in enumerate(dense_hits): rrf_scores[doc_id] = rrf_scores.get(doc_id, 0) + 1.0 / (60 + rank) for rank, (doc_id, _) in enumerate(sorted_bm25): rrf_scores[doc_id] = rrf_scores.get(doc_id, 0) + 1.0 / (60 + rank) return sorted(rrf_scores.items(), key=lambda x: x[1], reverse=True)[:top_k]

Local Engine
Miert qwen2.5:3b? Valasztas

  • Kivalo kodertes: Kiemelkedo teljesitmeny Python szintaxis ertelmezeseben es strukturalt JSON valaszokban.

  • Nem hasznal kulso Python SDK-t: tiszta httpx aszinkron klienssel kezeli a lekerdezeseket.
  • Tamogatja mind a teljes valaszt, mind az inkrementalis streaminget SSE esemenyekhez.
Biztonsagi izolacio Offline Rule
  • Az alkalmazas Docker kontenerben fut, halozata csak a helyi gep localhost-javal beszelget.
  • Nincs API kulcs, nincs regisztracio, nincs internet-fuggoseg.

Valos ideju esemenyfolyam (Server-Sent Events)

GET /events vegpont: live ertesitesek a bongeszo reszere polling nelkul

Reactivity
Miert SSE a WebSocket vagy Polling helyett? Architektura
  • Egyszeruseg: Standard HTTP kapcsolat, nincs szukseg bonyolult ketiranyu handshake-re vagy WS konyvtarra.
  • Auto-reconnect: A bongeszo beepitett EventSource API-ja automatikusan ujracsatlakozik megszakadas eseten.
  • Zero halozati terheles: Nem general masodpercenkenti felesleges HTTP kereseket (nincs periodikus polling).

Mire fognak rakérdezni az ertekelok a Part 2 defense soran?

Defense Ready
1. Miert hibrid a kereso? Kereses
  • Valasz: A tiszta vektoros kereses elteveszti az egzakt valtozo- es fuggvenyneveket, a BM25 viszont nem erti a jelentest.
  • A kettot RRF (Reciprocal Rank Fusion) algoritmussal kombinaljuk a tokeletes talalati aranyert.

  • Valasz: Determinisztikus AST szimbolum elofeloldassal.
  • Ha a kerdes egy szimbolum letezestere iranyul, az AST metaadatokbol azonnal tenykent injektaljuk a promptba, igy az LLM nem talalhat ki valaszt.
3. Bizonyitsd, hogy offline! Offline
  • Valasz: Allitsd le a wifit vagy mutasd meg a Docker kornyezet beallitasait.
  • Az Ollama a 127.0.0.1:11435 cimen helyben szamol, nincs kulso kulcs vagy API kapcsolat.
